# Latin Modern font assets

Unmodified Latin Modern 2.005 font files from the official CTAN distribution:
https://ctan.org/pkg/lm

Copyright 2003–2021 by B. Jackowski and J. M. Nowacki (on behalf of TeX Users Groups).
Based on Donald E. Knuth’s Computer Modern family.

Distributed under the GUST Font License. See GUST-FONT-LICENSE.txt and LPPL-1.3c.txt.
The upstream README is included unchanged as README. This folder contains only a font subset.

The complete, original font package, documentation, sources, and manifest are available at:
https://mirrors.ctan.org/fonts/lm.zip

Font binaries were downloaded unmodified from:
https://mirrors.ctan.org/fonts/lm/fonts/opentype/public/lm/

Files included:
- lmroman10-bold.otf
- lmroman10-bolditalic.otf
- lmroman10-italic.otf
- lmroman10-regular.otf
- lmroman12-bold.otf
- lmroman12-regular.otf

# STIX Two Math

STIXTwoMath-Regular.otf is an unmodified font from the official STIX v2.13b171 release:
https://github.com/stipub/stixfonts/releases/tag/v2.13b171

Archive: https://raw.githubusercontent.com/stipub/stixfonts/v2.13b171/zipfiles/static_otf.zip

Copyright 2001–2021 The STIX Fonts Project Authors. Released under SIL Open Font License 1.1.
See STIX-OFL.txt and STIX-FONTLOG.txt, both copied unchanged from the upstream repository.
This project bundles only the math font. The complete distribution is linked above.
